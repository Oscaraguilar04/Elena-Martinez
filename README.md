# Elena Martinez — Residential Real Estate Website Concept

A one-page marketing site for a **fictional** Sacramento family realtor. Built as a Fiverr / student portfolio piece to show a warm residential brand that is clearly different from a luxury editorial realtor site.

**This is not a real client.** Listings, statistics, and testimonials are concept-only.
